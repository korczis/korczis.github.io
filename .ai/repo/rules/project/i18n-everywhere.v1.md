# Rationale

The owner asked for every text to be translated using Zola's multilingual features, with tags,
derived and generic ("kazdy jeden text musi byt prelozeny, vyuzivat zola multilanguage features,
tags"). A translation that has to be remembered is a translation that will be missing; a gate
that reads every template cannot forget.

# Required behaviour

- `zola.toml` declares `[languages.cs]` and the `tags` taxonomy for both languages. Its translation
  tables are generated by `scripts/build-i18n.mjs` from `i18n/strings.toml` (one table per key, a
  value per language). Templates call `trans(key=..., lang=lang)`; texts with values use
  placeholders (`{n}`, `{date}`, `{list}`) replaced in the template.
- Data fields that are words have a `_cs` twin (`data/projects.toml`, `data/site.toml`); templates
  read them generically as `c["name" ~ sfx]`.
- Scripts read their texts through `KorczisHub.t(key, vars)` from `#i18n-data`, which the base
  layout writes per language, and format dates with `KorczisHub.locale`.
- Generated pages (categories, work) are written in both languages; their Czech descriptions are
  derived from data (category, language, last commit) or curated Czech words, never machine
  translation. Texts a repository wrote itself (descriptions, README excerpts) are shown as they
  are.
- Links follow the page's language (`lp`); assets load from the site root. Every page declares
  `hreflang` alternates, `x-default`, `og:locale` and `og:locale:alternate`; the navbar switches
  to the same page in the other language.
- Tags are derived by the generators (category name, languages) into `[taxonomies]`; tag pages are
  indexable collection pages with JSON-LD.

# Failure behaviour

`scripts/check-i18n.mjs` exits 1 on a `trans` key that does not exist, a visible template text
outside `trans()`, a data field without its `_cs` twin, or a page without its translation.
`build-i18n.mjs --check` exits 1 on stale translation tables or a key missing a language.

# Verification

```sh
node scripts/build-i18n.mjs --check && node scripts/check-i18n.mjs
```
